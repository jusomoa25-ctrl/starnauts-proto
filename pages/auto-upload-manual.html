1채널 연결 — 두 가지 방법

방법 A. 웹 클라이언트 팝업 (권장, 최초 1회 설정) — 이후에는 버튼 한 번으로 9채널 어느 계정이든 연결됩니다.

1
구글 클라우드 콘솔에서 웹 애플리케이션 클라이언트 생성
기존 프로젝트(YouTube Data API 사용 설정·테스트 유저 등록 완료) → Clients → Create client → 웹 애플리케이션. 승인된 자바스크립트 원본에 도구를 여는 주소(예: http://localhost:8000)를 등록. 리디렉션 URI는 불필요.
2
클라이언트 ID 저장 후 [채널 연결]
도구의 [1. 채널 연결] 탭에 ....apps.googleusercontent.com을 저장하고 [채널 연결] 클릭 → 계정 선택 팝업에서 채널 계정 선택 → 초록불 확인.

방법 B. 액세스 토큰 직접 입력 (현재 검증된 경로) — 데스크톱 타입 클라이언트만 있을 때. Claude에게 "채널명 토큰 발급해줘"라고 요청하면 해당 채널의 1시간짜리 토큰을 발급합니다. 붙여넣고 [토큰으로 연결]을 누르면 즉시 연결됩니다. 토큰은 저장되지 않습니다.

토큰은 약 1시간 유지됩니다. 만료되면 업로드 시작 시 자동으로 재연결을 요청합니다(방법 A) 또는 새 토큰을 발급받아 다시 붙여넣습니다(방법 B).

2업로드 절차 (발행 워크플로우)

1
영상 파일 선택
CapCut에서 내보낸 최종본. 파일 크기와 조각 수가 표시됩니다.
2
메타데이터 입력
제목은 Playlist | 접두 표준(자동 검사). 설명에는 타임스탬프·트랙리스트·TEAM PLAYSTARS LIST 소개 블록을 넣고, Suno 언급 줄 다음에 [Suno 라이선스 증빙 블록 삽입] 버튼으로 증빙 문구(EN+KO 정본)를 추가합니다. 기본 언어는 채널 표준인 영어(en).
3
다국어 번역 생성 · 검수
기본 8개 언어가 미리 선택되어 있습니다. 필요하면 언어를 추가하고 [Gemini로 번역 생성] → 언어별 미리보기에서 직접 수정. 번역은 업로드 시 자동으로 함께 등록됩니다. 고유명사(채널명·아티스트명)·링크·타임스탬프·Playlist | 접두사는 번역되지 않도록 지시되어 있습니다.
4
공개 설정 · 예약
예약 공개(추천) 선택 후 슬롯 프리셋 버튼으로 다음 발행 슬롯을 채웁니다 — 게코 금 21시 · 테디 일 22시 · 웨일 수 22시 · 푸쿠 목 21시 · 펭 토 20시 (KST).
5
썸네일 선택
2MB 초과 파일은 업로드 시 자동 압축됩니다. 맞춤 썸네일은 채널 전화 인증 필수.
6
업로드 시작
진행바로 조각 전송을 확인합니다. AI 생성 콘텐츠 고지는 기본 ON(채널 영구 규칙) — 끄지 마세요. 아동용은 기본 아니오.
7
Studio 수동 마무리
완료 카드의 체크리스트대로: 영상 확인 → 핀 댓글 작성·고정(문안은 노션 플리 운영 정본) → 엔드스크린·재생목록 → 리믹스 허용 안 함 설정 → Claude에게 chboard 현황판 갱신 요청.
이 절차는 기존 업로드 7단계 표준(노션 자동화 매뉴얼 정본)과 동일한 결과를 만듭니다. 도구 사용 시 사용자가 하는 일은 내보내기·썸네일·Studio 마무리뿐입니다.
