OAuth 클라이언트 발급 (최초 1회)

1
구글 클라우드 콘솔 접속
console.cloud.google.com/auth/overview — 프로젝트가 없으면 새로 만들고, 동의 화면에서 Get started를 누릅니다. 앱 이름은 아무거나(예: STARNAUTS Upload).
2
동의 화면 구성
User type은 외부(External), 본인 이메일 입력 후 동의·Create·Continue. Audience → Add user에서 본인 구글 계정(채널 소유 계정)을 테스트 유저로 등록합니다.
3
YouTube Data API v3 사용 설정
API 및 서비스 → 라이브러리에서 YouTube Data API v3를 검색해 사용 설정합니다.
4
클라이언트 생성
Clients → Create client → 웹 애플리케이션. 승인된 자바스크립트 원본에 이 페이지를 여는 주소를 등록합니다(예: http://localhost:8000). 리디렉션 URI는 필요 없습니다(토큰 팝업 방식).
5
클라이언트 ID 저장
발급된 ....apps.googleusercontent.com을 복사해 [1. 채널 연결] 탭에 저장하고 채널 연결을 누르면 끝. 이후에는 연결 버튼만 누르면 됩니다.
테스트 모드에서는 등록한 테스트 유저 계정만 연결할 수 있고, 연결 토큰은 약 1시간 유지됩니다. 화면이 막히면 해당 화면을 캡처해 AI에게 다음 단계를 물어보는 것이 가장 빠릅니다.

알아둘 제한

·
15분 초과 영상 = 채널 전화 인증 필수
youtube.com/verify — 1~2시간 플레이리스트 영상은 반드시 필요합니다. 맞춤 썸네일에도 전화 인증이 필요합니다.
·
하루 API 업로드 한도 약 6개
구글 기본 할당량 10,000 중 업로드 1건이 1,600을 소비합니다. 플레이리스트 채널 운영에는 충분합니다.
·
예약 공개는 유튜브가 처리
업로드가 끝나면 컴퓨터를 꺼도 됩니다. 예약 시각(KST 입력)은 자동으로 UTC로 변환되어 등록됩니다.
·
번역 검수
Gemini 번역 결과는 등록 전에 언어별 미리보기에서 직접 수정할 수 있습니다. 고유명사(채널명·아티스트명)와 링크는 번역하지 않도록 지시되어 있습니다.
