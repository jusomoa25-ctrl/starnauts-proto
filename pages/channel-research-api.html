발급 방법 안내

YouTube Data API v3는 채널·영상의 메타데이터를 가져오는 데 사용됩니다. 무료이며 일일 10,000 쿼터가 기본 제공됩니다 (채널 1회 분석 ≈ 약 5~12 쿼터).

1

Google Cloud Console에 접속

평소 사용하는 Google 계정으로 로그인하세요. 처음이라면 약관 동의 화면이 한 번 나옵니다.

Google Cloud Console 열기 ↗
2

새 프로젝트 만들기

상단 좌측 프로젝트 선택 드롭다운(프로젝트 선택)을 누르고 우측 상단 새 프로젝트를 클릭해요. 이름은 자유롭게(channel-research 등) 적고 만든 뒤 그 프로젝트로 전환해 주세요.

3

YouTube Data API v3 사용 설정

왼쪽 메뉴 API 및 서비스 → 라이브러리로 이동해 검색창에 YouTube Data API v3를 입력하고, 결과를 눌러 파란색 사용(ENABLE) 버튼으로 활성화해요.

바로 활성화 페이지로 ↗
4

API 키 만들기

왼쪽 메뉴 API 및 서비스 → 사용자 인증 정보(Credentials)로 이동해 상단 + 사용자 인증 정보 만들기 → API 키를 클릭하면 AIzaSy…로 시작하는 키가 생성돼요. 복사 버튼으로 클립보드에 담아두세요.

5

(권장) 키 사용 범위 제한

방금 만든 키의 연필 아이콘 → API 제한사항에서 키 제한 → YouTube Data API v3만 선택해 저장하면 다른 API로 오·남용되는 것을 막을 수 있어요. 애플리케이션 제한사항은 이 도구가 브라우저에서 직접 호출하므로 없음으로 둬도 됩니다.

6

위쪽 입력칸에 붙여 넣기

복사한 키를 맨 위 YouTube Data API v3 키 칸에 붙여 넣고 아래쪽 저장을 누르면 상태가 "연결됨"으로 바뀝니다.

💡 쿼터 안내 · 무료 한도는 하루 10,000 units. 채널 1건 분석에 약 5~12 units가 소모되니 하루 700건 이상도 가능해요. 한도를 초과하면 quotaExceeded 오류가 뜨고 다음 날(태평양 시간 자정) 자동 리셋됩니다.

Gemini는 수집한 데이터로 5개 영역 점수와 전문 피드백을 생성합니다. 무료 등급으로 시작할 수 있어요. 사용 모델은 gemini-2.5-flash입니다.

1

Google AI Studio 접속

Google 계정으로 로그인합니다. (YouTube 키와 같은 계정이어도 됩니다.)

AI Studio · API 키 페이지 ↗
2

Create API key

API 키 만들기 / Create API key를 누르고 프로젝트를 선택(또는 새로 생성)하면 AIzaSy… 키가 발급돼요.

3

위쪽 입력칸에 붙여 넣기

발급된 키를 Gemini API 키 칸에 붙여 넣고 저장 → 연결 테스트로 정상 동작을 확인하세요.

💡 무료 등급은 분당·일일 호출 수에 한도가 있어요(대략 분당 ~10회·일일 ~250회, 변동 가능). 초과 시 RESOURCE_EXHAUSTED가 뜨면 1~2분 후 다시 시도하면 됩니다.

이 도구는 BYOK(Bring Your Own Key) 방식입니다. 입력한 키는 서버로 전송되지 않습니다.

·

키 저장 위치

키는 이 브라우저의 localStorage에만 저장됩니다(starnauts_yt_key, starnauts_key_gemini). 공용 PC에서는 사용 후 "키 삭제"를 눌러 지워 주세요.

·

호출 경로

분석 시 브라우저가 Google API로 직접 요청합니다. 스타너츠 서버는 키를 보지도, 저장하지도 않습니다.

·

키 노출 주의

키를 캡처·공유하지 마세요. 노출이 의심되면 Google Cloud / AI Studio에서 해당 키를 삭제(재발급)하면 즉시 무효화됩니다.
